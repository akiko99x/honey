# Contributing

Run these checks before opening a pull request:

```bash
(cd agent && go test ./...)
(cd agent && go run github.com/bufbuild/buf/cmd/buf@v1.47.2 generate ../proto)
(cd master && cargo fmt -- --check && cargo test --locked)
(cd master && cargo check --locked --features dial-acceptor,acme)
node --check web/app.js
bash -n scripts/*.sh
```

The Buf CLI and both remote Go protobuf plugins are version-pinned. After a
change under `proto/`, run `scripts/proto-gen.sh` and commit the regenerated
files under `agent/gen`; Rust stubs are generated by `master/build.rs`.

Database changes require a new forward-only SQLx migration. Do not edit an
existing released migration. Protocol/core/transport changes must update both
master validation and the relevant agent config builder, plus subscription
tests when client output changes.

Never commit credentials, environment files, databases, certificates, private
keys, enrollment bundles, subscription URLs, or artifacts from the isolated
smoke environment.

By submitting a contribution, you agree to license it under
`AGPL-3.0-only`, the license of the project. Copyright remains with the
respective contributor. No contributor agreement granting commercial
relicensing rights is currently in effect.

Use the pull request template and keep changes scoped. Security vulnerabilities
must be reported privately as described in `SECURITY.md`; do not disclose them
in an issue or pull request.
